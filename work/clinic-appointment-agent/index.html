Clinic appointment agent

A WhatsApp agent that lets patients book, reschedule and cancel appointments in chat, using the clinic's own ERP as the source of truth.

Type
AI agent proof of concept
Status
Built and demoed
Sector
Healthcare
Built with
Wati AI agents, REST APIs

The problem

Booking, rescheduling and cancelling depend on live availability in the clinic's ERP. A scripted chatbot could not do it; the agent had to read and write real data safely.

What I built

  • An AI agent on Wati that handles appointment management end to end in chat.
  • Nine live REST API actions into the clinic's ERP covering booking, rescheduling and cancellations.
  • Answers to general questions from a knowledge base, so the agent only calls the ERP when it needs to.

Key decisions

  • Use the clinic's ERP as the single source of truth through its APIs, rather than a separate booking sheet.
  • Break the flow into small API actions so each step can be tested and its failures handled on their own.
  • Build on the prospect's real process, so the demo shows their workflow, not a generic one.

Result

A working proof of concept on the prospect's own process, demoed end to end. My part: discovery, agent design, API wiring, testing and the demo.
