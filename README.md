# Parth Chauhan, portfolio

Personal portfolio of Parth Chauhan, Senior Solutions Engineer. Plain HTML, CSS and JavaScript with no build step, hosted on GitHub Pages.

Live: https://parthchauhan0011.github.io/portfolio/

## What's here
- `index.html`: home page (hero, features I originated, tagline, impact at Wati, proofs of concept, how I work, experience, FAQ, contact)
- `work/<case-study>/index.html`: four case study pages (estimators, solutions team, ERP strategy, clinic proof of concept). Links point at index.html so the site also works opened from a local folder
- `privacy/index.html`: privacy and terms
- `style.css`, `script.js`: shared styles and behaviour
- `assets/Parth_Chauhan_Resume_2026.pdf` and `.docx`: current resume in PDF and Word
- `assets/fonts/`: Geist variable font, self hosted (SIL Open Font License, see `LICENSE-OFL.txt`)
- `assets/img/`: screenshots (client names, rates and internal links blurred), profile photo, favicon and social image
- Icons: Phosphor (MIT), inlined as an SVG sprite in each page

## Design rules
Built to the landing-page-design skill: Geist only, named text styles on the Tailwind type scale, spacing tokens only, Tailwind radii, flat backgrounds, gradient only on hero headings, base curve cubic-bezier(0.22,1,0.36,1) for all motion, reduced motion respected.
