# Parth Chauhan · Portfolio

Personal portfolio built with plain HTML, CSS and JavaScript (no build step).

Live: https://parthchauhan0011.github.io/portfolio/

## Files
- `index.html` – page structure and content
- `style.css` – design system, layout, animations, responsive rules
- `script.js` – interactive chat, feature tabs, project filters, deal-process stepper, 3D tilt, scroll effects
- `assets/Parth_Chauhan_Resume_2026.pdf` – current resume (also copied to `assets/Parth_resume.pdf` so the old link keeps working)
- `assets/profilepic.jpg` – placeholder photo for the chat avatar; replace with your own square photo using the same file name
- `assets/logos/` – tool icons from Simple Icons v16.33.0 (simpleicons.org); trademarks belong to their owners

## Deploy
Replace the contents of the `portfolio` repo with these files and push. GitHub Pages serves `index.html` automatically.
